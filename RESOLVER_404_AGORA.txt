│ OPÇÃO 1: PÁGINA DE DIAGNÓSTICO (MAIS FÁCIL)                │
└─────────────────────────────────────────────────────────────┘

1. Abra no navegador:

   http://localhost:8080/diagnostic/teste

   (pode usar qualquer slug, a página vai mostrar os disponíveis)

2. A página vai te mostrar:
   ✅ Qual é o slug correto
   ✅ Se precisa executar SQL
   ✅ Qual é o erro exato

3. Copie a URL do cardápio que aparece lá

═══════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────┐
│ OPÇÃO 2: EXECUTAR SQL MANUALMENTE                          │
└─────────────────────────────────────────────────────────────┘

1. Abra este link:

   https://supabase.com/dashboard/project/wisikawnpzrrfzqutatl/sql

2. Cole EXATAMENTE isto:

DROP POLICY IF EXISTS "Public can view active restaurants" ON restaurants;
CREATE POLICY "Public can view all restaurants" ON restaurants FOR SELECT USING (true);

3. Clique em RUN

4. Pronto! Agora tente acessar o cardápio novamente
